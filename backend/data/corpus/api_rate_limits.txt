API Developer Policy §4.2 — Rate Limits

Free-tier API keys are limited to 60 requests per minute and 10,000 requests per day. Exceeding these limits will result in HTTP 429 Too Many Requests responses. Retry-After headers indicate when the next request window opens.

Pro-tier keys allow 600 requests per minute and 1,000,000 requests per day. Enterprise keys have no hard rate limits but are subject to fair-use review. Burst allowances permit up to 5× the per-minute rate for up to 10 seconds before throttling begins.

To request a rate limit increase, submit a ticket at support.aiflow.dev/rate-limits with your use case and projected volume.
